# iOS 快捷指令进阶配置——论文检索 + Todo 写入

## 快捷指令 1：提交论文关键词

这个快捷指令由晚间推送通知触发，也可以手动运行。

**动作：**
1. **询问输入**
   - 提示语：`明天想搜什么社会学论文关键词？`
   - 输入类型：文本
   - 变量名：`Keywords`

2. **获取 URL 内容**
   - URL: `http://你的服务器IP:8000/routines/keywords`
   - 方法: `POST`
   - 请求头:
     - `Authorization`: `Bearer 你的API_KEY`
     - `Content-Type`: `application/json`
   - 请求体（JSON）: `{"keywords": "{{Keywords}}"}`

3. **显示结果**

**命名为：** `提交论文关键词`（必须和推送通知里的动作名一致）

**添加到主屏幕，或通过 Siri 触发：** "嘿 Siri，提交论文关键词"

## 快捷指令 2：把论文保存到备忘录

这个快捷指令通过 iOS 自动化每天早上 8:30 自动运行，把当天检索的论文写入备忘录。

**动作：**

1. **获取 URL 内容**
   - URL: `http://你的服务器IP:8000/routines/papers/latest?limit=10`
   - 方法: `GET`
   - 请求头: `Authorization: Bearer 你的API_KEY`

2. **从输入中获取字典** → 解析 JSON 响应

3. **获取字典中的值** → 键名 `papers` → 存为变量 `Papers`

4. **文本**（构建备忘录内容）
   ```
   今日社会学论文检索
   更新时间：{{当前日期}}
   ────────────────
   ```

5. **重复操作**（对 `Papers` 中每项重复）：
   - **文本**：
     ```
     [{{重复项目.title}}]
     作者：{{重复项目.authors}}
     年份：{{重复项目.year}}
     链接：{{重复项目.url}}
     ```
   - **在文本后面追加文本**（添加分隔线 `────────────────`）

6. **在备忘录中创建备忘录**
   - 标题: `今日论文 {{当前日期}}`
   - 正文: 上面构建的文本
   - 文件夹: `论文笔记`（提前在备忘录里创建）

## 快捷指令 3：把论文添加到提醒事项

替代备忘录，将每篇论文作为单独的提醒事项添加。

**动作：**

1. **获取 URL 内容** → GET `/routines/papers/latest?limit=5`

2. **从输入中获取字典** → 解析响应

3. **重复操作**（对每篇论文）：
   - **在提醒事项中添加新提醒**
     - 标题: `{{重复项目.title}}`
     - 备注: `{{重复项目.url}}`
     - 列表: `待读论文`（提前创建此列表）

## iOS 自动化设置（让快捷指令自动运行）

在「快捷指令」→「自动化」→「+"：

**自动化 1：每天 8:30 保存论文到备忘录**
- 触发器: 时间 → 每天 08:30
- 动作: 运行快捷指令「论文存入备忘录」
- 立即运行: ✅（关闭「运行前询问」）

**自动化 2：收到 ntfy 通知后提交关键词（可选）**
- 触发器: App → ntfy 打开时
- 动作: 运行快捷指令「提交论文关键词」

## 网页控制台

服务器运行后，访问以下地址管理所有功能：

```
http://你的服务器IP:8000/dashboard
```

功能：
- 开关晚间询问 / 早晨检索
- 直接提交关键词（无需手机快捷指令）
- 查看最近检索的论文列表
- 发送测试推送通知

## ntfy 推送通知动作按钮

晚间推送通知包含一个「提交关键词」按钮，点击后直接跳到快捷指令输入界面。

这是通过 ntfy 的 `Actions` 请求头实现的：
```
Actions: view, 提交关键词, shortcuts://run-shortcut?name=提交论文关键词
```

**前提：**
1. 快捷指令必须命名为 `提交论文关键词`
2. iOS 设备上已安装 ntfy app 并订阅了你的 topic
3. 点击通知按钮后，iOS 会弹出「是否打开快捷指令」确认（首次需授权）
