# iOS 快捷指令：每日论文速递发送到 iMessage 群组

服务器每天早上完成论文检索后，会生成一段格式化的「每日论文速递」存入数据库。
这个快捷指令从服务器取回该文本，通过 iOS 原生「发送信息」动作发到你指定的 iMessage 群组。

---

## 快捷指令配置

**命名为：** `发送论文速递`

**动作：**

1. **获取 URL 内容**
   - URL: `http://你的服务器IP:8000/routines/digest/latest`
   - 方法: `GET`
   - 请求头:
     - `Authorization`: `Bearer 你的API_KEY`

2. **从输入中获取字典** → 解析 JSON 响应

3. **获取字典中的值** → 键名 `content` → 存为变量 `DigestText`

4. **发送信息**
   - 收件人: 选择你的 iMessage 群组（首次设置时从通讯录/最近联系人中选定）
   - 信息: `DigestText`
   - 关闭「发送前询问」（在自动化中使用时需要关闭，否则每次都弹确认）

5. **（可选）通知**
   - 显示通知「论文速递已发送」

**提示：** 「发送信息」动作只支持 iMessage / 短信，不支持微信。
如需发到微信群，参见下方「微信群方案」。

---

## iOS 自动化设置（让快捷指令定时自动运行）

在「快捷指令」→「自动化」→「+」：

**自动化：每天上午 9:00 发送论文速递到 iMessage 群**

| 设置项 | 值 |
|--------|-----|
| 触发器 | 时间 → 每天 09:00 |
| 动作 | 运行快捷指令「发送论文速递」 |
| 立即运行 | ✅（关闭「运行前询问」） |

> 时间设置为论文检索完成后（服务器 `morning_search_cron` 默认 08:00），
> 建议这里设为 08:45 或 09:00，确保摘要已生成。

---

## 微信群方案（需手动触发或用快捷指令复制文本）

iOS 快捷指令无法直接向微信群发送消息（微信不开放 URL Scheme 发送接口）。
替代方案：

**方案 A：自动复制到剪贴板 + 提醒**
1. 「获取 URL 内容」→ 取 `content` 字段（同上 1-3 步）
2. **复制到剪贴板**（动作：「设定剪贴板」→ `DigestText`）
3. **显示通知**：「论文速递已复制，打开微信粘贴到群里」
4. 设置为每天 09:00 自动化运行

打开微信群 → 长按输入框 → 粘贴 → 发送。

**方案 B：使用 ntfy 通知本身作为内容**

服务器在推送早间通知时附带了完整摘要，
你也可以直接在 ntfy 通知里长按 → 复制消息内容 → 粘贴到微信群。

## 验证摘要是否已生成

```bash
curl http://你的服务器IP:8000/routines/digest/latest \
  -H "Authorization: Bearer 你的API_KEY"
```

成功响应示例：
```json
{
  "id": 1,
  "date": "2026-04-21",
  "keywords": "digital inequality",
  "content": "📚 04月21日 社会学论文速递｜digital inequality\n\n1. ...\n──────\n• ...",
  "send_time": null,
  "created_at": "2026-04-21T08:03:22.456789+00:00"
}
```

如果返回 404，说明今天的论文检索还未运行或未找到关键词，等到明天早上服务器运行后再试。

## 手动触发（测试用）

在服务器端手动触发一次完整的早间流程：

```bash
curl -X POST http://你的服务器IP:8000/notify \
  -H "Authorization: Bearer 你的API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"title":"手动测试","message":"这是一条手动推送测试消息"}'
```

或直接在 Web 控制台（`/dashboard`）提交关键词后，
通过 APScheduler 管理界面或重启服务器触发早间任务。
